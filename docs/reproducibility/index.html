Determinism

phisat2/utils/seed.py seeds Python, NumPy, PyTorch, and CUDA settings. The CLI also calls Lightning's worker seeding for each run seed.

  • Training seeds come from SEEDS; one output directory is created per seed.
  • Evaluation uses the CLI --seed argument, which defaults to 42; the current make eval target leaves that default in place.
  • Downstream train/validation splitting is seed-dependent.

Remaining variance

  • External dataset preprocessing and Zarr content.
  • Hardware and backend differences.
  • Distributed training order effects.

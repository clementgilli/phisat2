Troubleshooting

Common errors and quick fixes.

DocsTroubleshooting

Common failures

  1. Invalid task/dataset: check phisat2/tasks/specs.py; each task has its own dataset set.
  2. Unknown model: run make list-models. The active registry contains phisatnet and TerraMind teacher names.
  3. Unknown dataloader: run make list-dataloaders. Valid names are downstream, triplets, and synthetic.
  4. TerraTorch import error: run make install; TerraMind backbones require TerraTorch.
  5. Loader path error: ensure ROOT_DIR points to an expected Zarr dataset tree or triplets root.
  6. Knowledge distillation fails: distillation_kd is registered but the CLI module is not implemented yet.
  7. CUDA/DDP mismatch: test one device first; then enable AUTO_DDP=true on multi-GPU.

Fast debug flow

make check
make list-models
make list-dataloaders
make smoke

If smoke passes, most remaining failures are data paths, task/dataset compatibility, or checkpoint format.

Scripts

  • src/adaptation/train_distillation_student.py: SIM-to-REAL encoder distillation.
  • src/adaptation/train_distillation_teacher.py: teacher/student feature matching.
  • src/downstreams/train_downstream.py: older frozen-encoder downstream training.
  • src/downstreams/train_pretext.py: older climate, geolocation, and reconstruction probes.
  • src/dataset/triplets_dataset_pipeline/: raw triplet dataset preparation pipeline.

Boundary

These scripts are separate from the supported phisat2/cli/cli.py and Makefile workflow. Prefer the package CLI for new runs unless you are reproducing old research experiments.

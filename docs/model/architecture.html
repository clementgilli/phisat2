Model registry

phisat2/models/registry.py is the source of truth.

  • phisatnet: student PhiSatNet CNN encoder.
  • terramind_v1_tiny, terramind_v1_small, terramind_v1_base, terramind_v1_large: TerraTorch teacher backbones.

No phisat2_geoaware, Prithvi, DOFA, SECO, SSL4EO, Satlas, or Myriad models are registered in the active package.

Build model contract

build_model() returns a ModelBundle. Which fields are populated depends on the task.

TaskBundle fieldsNotes
pretrain_reconstructionmodelPhiSatNet encoder plus reconstruction decoder.
domain_adaptationteacher, studentBoth PhiSatNet encoders initialized from --weights.
eval_domain_gapteacher, student, decodersLoads encoder and decoder checkpoints.
Downstream tasksmodelComposedModel with a frozen encoder during downstream training.

Task heads

  • Spatial tasks (segmentation, pixel_regression, pretrain_reconstruction) use PhiSatNetDecoder.
  • Classification and other non-spatial outputs use MultiScaleClassificationHead.

The PhiSatNet encoder emits four feature maps. The decoder upsamples those maps through skip connections and emits task-specific channels.

TerraTorch backbones

TerraMind model names are wrapped by TerraTorchBackboneEncoder, which maps the active input bands onto the backbone's registered pretraining bands.

For downstream tasks, passing a teacher model name currently falls back to the phisatnet architecture and prints an informational message.

Downstream layout

ROOT_DIR can point directly at a dataset .zarr or at a directory containing the expected Zarr store.

  • lulc / lc: phileo-bench_lc.zarr
  • burned: burned_area_dataset.zarr
  • clouds: clouds_dataset.zarr
  • floods: floods_dataset.zarr
  • roads: phileo-bench_roads.zarr
  • building: phileo-bench_building.zarr
  • fire: fire_dataset.zarr

The loader reads trainval/ for train and validation splits, test/ for testing, and samples val from trainval using the run seed.

Triplets layout

The triplets dataloader expects ROOT_DIR/pairs/ plus split CSVs under ROOT_DIR/splits/ when used through the CLI registry.

ROOT_DIR/
  pairs/
  splits/
    train.csv
    val.csv
    test.csv

The CLI automatically selects triplets for paired tasks, so those tasks do not need explicit DATASET or DATALOADER values.

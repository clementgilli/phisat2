CLI & Make commands

Short command reference for daily workflows.

DocsCLI

CLI usage

uv run --python 3.13 python -m phisat2.cli.cli fit \
  --task segmentation \
  --dataset lulc \
  --model phisatnet \
  --dataloader downstream \
  --seeds 0 1 \
  --root-dir /path/to/data \
  --output-dir runs \
  --max-epochs 5 \
  --batch-size 8 \
  --crop-size 224 \
  --lr 1e-4 \
  --num-workers 4 \
  --accelerator cpu \
  --devices 1 \
  --precision 32-true \
  --no-pretrained

Use python -m phisat2.cli.cli list-models and list-dataloaders to inspect registries.

One-liner quick map

GoalCommand
Verify packagemake check
List modelsmake list-models
List loadersmake list-dataloaders
Smoke runmake smoke
Synthetic fast dev runmake fast-dev-run TASK=segmentation DATASET=clouds MODEL=phisatnet DATALOADER=synthetic PRETRAINED=false ACCELERATOR=cpu DEVICES=1 NUM_WORKERS=0
Real downstream runmake train-segmentation DATASET=lulc MODEL=phisatnet DATALOADER=downstream ROOT_DIR=/path/to/data

Auto-detected paired tasks

pretrain_reconstruction, domain_adaptation, distillation_kd, and eval_domain_gap set DATASET=triplets and DATALOADER=triplets inside the CLI. Knowledge distillation is registered but not implemented by the CLI module yet.

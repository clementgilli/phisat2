Repository Structure

  • phisat2/: Main package with training, models, data loading, evaluation, and CLI.
  • configs/: Make experiment configs for local or cluster runs.
  • tests/: Unit tests.
  • src/: Legacy research and dataset scripts.
  • docs/: This documentation.

Quick Commands

make install                          # Install dependencies with uv
make check                            # Byte-compile the phisat2 package
make smoke                            # Run a synthetic one-batch smoke test
make list-models                      # See registered models
make list-dataloaders                 # See registered dataloaders
make train-segmentation DATASET=lulc MODEL=phisatnet DATALOADER=downstream ROOT_DIR=/path/to/data

Checkpoints & logs

Where outputs are written during training and evaluation.

DocsCheckpoints & logs

Training output path

OUTPUT_DIR/TASK/DATASET/MODEL/SUBSET/seed_N/

  • checkpoints/best.ckpt: checkpoint with minimum val_loss.
  • checkpoints/last.ckpt: last saved training state.
  • wandb/: Weights & Biases run files when the logger is active.

SUBSET is full_dataset unless SUBSET_CSV is set, in which case the CSV stem is used.

Evaluation output path

OUTPUT_DIR/TASK/DATASET/MODEL/SUBSET/eval_seed_N/

  • test_metrics.json: first Lightning test metrics dictionary.
  • Segmentation and pixel-regression evaluation can also write debug images under the evaluation directory.

Resume

Set RESUME=true to resume from checkpoints/last.ckpt when it exists for the selected seed output directory.

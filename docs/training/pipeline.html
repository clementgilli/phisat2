Training pipeline

End-to-end flow used by Make targets and the CLI.

DocsTraining

Execution path

  1. Make target calls uv run --python 3.13 python -m phisat2.cli.cli fit ... or test ....
  2. CLI parses command and validates task, dataset, model, and dataloader.
  3. Paired tasks auto-select triplets; downstream tasks require explicit dataset and dataloader.
  4. resolve_task_spec sets output size, target key, and loss family.
  5. For each seed: set RNG seeds, build datamodule, build model bundle, wrap with a Lightning module.
  6. Lightning Trainer runs fit or test with callbacks, logger, and hardware config.

Training modules

  • DownstreamModule: freezes the encoder and trains task heads with AdamW and cosine LR scheduling.
  • SSLPretrainModule: masks simulated PhiSat-2 imagery and reconstructs visible/masked bands.
  • DomainAdaptationModule: freezes the teacher encoder and aligns student real-image features to simulated teacher features.

knowledge_distillation reaches NotImplementedError in phisat2/cli/cli.py; treat it as unfinished CLI work.

Defaults and hardware

  • Optimizer: AdamW.
  • Optimizer LR source: Make LR or CLI --lr.
  • Checkpointing saves best.ckpt by minimum val_loss and last.ckpt.
  • Fast-dev mode disables checkpoint callbacks through the CLI path.

Auto-DDP converts to DDP only when --auto-ddp is set, multiple CUDA devices are available, and accelerator/devices/strategy are still auto.

Common Make entry points

make smoke
make fast-dev-run TASK=segmentation DATASET=clouds MODEL=phisatnet DATALOADER=synthetic PRETRAINED=false ACCELERATOR=cpu DEVICES=1 NUM_WORKERS=0
make train-segmentation DATASET=lulc MODEL=phisatnet DATALOADER=downstream ROOT_DIR=/path/to/data SEEDS="42 7 6" EPOCHS=100
make pretrain MODEL=phisatnet ROOT_DIR=/path/to/triplets SEEDS="42"
make domain-adaptation MODEL=phisatnet ROOT_DIR=/path/to/triplets WEIGHTS=/path/to/pretrained_sim.pth

Available dataloaders: downstream, triplets, synthetic.

Config files and cluster submission

Reusable experiment settings live under configs/*.mk. Pass one with EXPERIMENT=configs/name.mk.

make train EXPERIMENT=configs/lulc_full.mk
make submit-train EXPERIMENT=configs/lulc_full.mk

Submit targets render scripts/runner_template.pbs and call qsub.

Task-sensitive defaults

  • Start with make smoke or make fast-dev-run before scaling to real data.
  • Reduce BATCH_SIZE first for memory pressure, then reduce CROP_SIZE.
  • Use NUM_WORKERS=0 when debugging loader failures locally.
  • Use WEIGHTS for encoder initialization during downstream, pretraining-derived, or domain-adaptation flows.

Evaluation notes

How to run trained checkpoints on test data.

DocsEvaluation

Checkpoint workflow

make eval \
  TASK=segmentation \
  DATASET=lulc \
  MODEL=phisatnet \
  DATALOADER=downstream \
  ROOT_DIR=/path/to/data \
  CKPT_PATH=/path/to/best.ckpt

CKPT_PATH maps to the CLI --weights argument for normal downstream evaluation.

Direct CLI workflow

uv run --python 3.13 python -m phisat2.cli.cli test \
  --task segmentation \
  --dataset lulc \
  --model phisatnet \
  --dataloader downstream \
  --root-dir /path/to/data \
  --weights /path/to/best.ckpt

Metrics are written to OUTPUT_DIR/TASK/DATASET/MODEL/SUBSET/eval_seed_N/test_metrics.json.

Output shape

  • Segmentation: [B, classes, H, W].
  • Pixel regression: [B, 1, H, W].
  • Classification: [B, classes]; currently fire has 4 classes.

There is no separate single-image inference CLI. Use the same model and datamodule path as training, or write a short script around build_model() with explicit input_bands.
